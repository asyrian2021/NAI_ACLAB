# NAI ACLAB Studio

> **과거 버전 사용자는 [1.x 사용법과 다운로드 안내](docs/LEGACY_V1.md)로 이동하세요.**

NovelAI 작가 조합을 무작위로 생성하고, 결과를 크게 감상·비교하는 Windows 데스크톱 앱입니다.

## Windows에서 실행

[최신 Windows x64 설치 파일](https://github.com/asyrian2021/NAI_ACLAB/releases/latest/download/NAI-ACLAB-2.0.9-Windows-x64-setup.exe)을 내려받아 설치한 뒤 시작 메뉴의 **NAI ACLAB**을 실행합니다. [릴리스 페이지](https://github.com/asyrian2021/NAI_ACLAB/releases/latest)에서 변경 사항도 확인할 수 있습니다.
사용자는 Python, Node.js 또는 Rust를 설치할 필요가 없습니다. WebView2가 없는 PC에서는 설치 프로그램이 런타임을 내려받습니다.

Windows x64용입니다. 앱 실행 시 새 버전을 확인하고, 상단 업데이트 버튼으로 내려받아 설치할 수 있습니다.
상단 메뉴와 하단 진행 상태는 항상 표시되며, 가운데 작업 영역만 스크롤됩니다. 대기열 상세 창은 하단 상태창 바로 위에서 열립니다.

## 작업실

- **감상:** 이미지 한 장을 크게 표시합니다. 좌우 화살표로 이전/다음 이미지를 선택합니다.
- **비교:** `기준으로 고정`으로 한 장을 고정한 채 다른 결과를 선택합니다. 2×/4× 확대 후 드래그하면 두 이미지가 함께 이동합니다.
- **모아보기:** 결과를 격자로 보고, 이미지 더블클릭으로 감상 화면으로 돌아갑니다.
- **집중 보기:** `F`로 양옆 패널을 접습니다. `Esc`로 돌아갑니다.
- **즐겨찾기:** 하트로 선택한 결과를 모아볼 수 있습니다. 작가 추첨에는 영향을 주지 않습니다.
- **이 조합으로 이어서:** 이미지의 작가 가중치와 순서를 그대로 불러옵니다. 왼쪽에서 수치·순서를 수정하거나 `랜덤으로 전환`할 수 있습니다.
- 선택한 이미지의 **타율 테스트** 버튼은 해당 작가 조합을 고정해 타율 테스트 메뉴로 이동합니다. **가이던스 테스트** 버튼은 해당 이미지와 시드를 선택한 상태로 테스트 메뉴를 엽니다.
- 생성 중에도 현재 보고 있는 이미지는 유지됩니다. 완료한 이미지는 매 장마다 저장됩니다.

오른쪽 패널은 작가 조합, 전체 프롬프트, 네거티브, 시드와 복사 기능을 제공합니다. 예전 버전에서 원문 프롬프트를 저장하지 않은 기록은 원문을 복원할 수 없습니다.

## 프롬프트

**프롬프트** 메뉴는 두 영역으로 나뉩니다.

1. **공통 설정:** 퀄리티와 공통 네거티브. 모든 프리셋이 공유하며 프리셋 전환 시 유지됩니다.
2. **개별 프리셋:** 이름, 베이스 프롬프트, 캐릭터별 프롬프트와 네거티브를 하나의 세트에 저장합니다.

조립 순서는 `베이스, 작가 태그, 공통 퀄리티 | 캐릭터 1 | 캐릭터 2`입니다.
네거티브는 `공통 네거티브 | 캐릭터 1 네거티브 | 캐릭터 2 네거티브`이며 빈 중간 슬롯도 유지합니다.

변경 사항은 입력을 잠시 멈추면 자동 저장됩니다. 상단에서 저장 상태를 확인할 수 있으며, 비어 있는 숫자나 잘못된 범위는 수정하기 전까지 저장되지 않습니다. 생성 버튼도 현재 설정을 저장합니다.

## 랜덤 조합

**작가** 메뉴에서 그룹별 작가 태그, 최소·최대 가중치, 간격, 추첨 인원을 설정합니다.
추첨 인원은 최소·최대 범위로 설정합니다. 매 이미지마다 범위 안의 정수 인원을 균등하게 뽑습니다. 최소와 최대가 같으면 고정 인원이며, **등록 작가 전체 사용**을 켜면 모두 사용합니다. 등록 인원이 부족하면 실제 범위는 등록 인원으로 제한됩니다. 기존 인원 설정은 그대로 이어집니다.

- 작가를 균등하게 비복원 추첨합니다.
- 범위 안의 가중치 후보를 균등하게 선택합니다. 간격이 최대값에 정확히 도달하지 않으면 최대값 이하의 마지막 후보까지 사용합니다.
- 생성된 작가 태그 순서를 매번 섞습니다.
- 고정 조합은 순서와 가중치를 유지합니다.
- 평가·평점·학습과 학습에 따른 확률 보정은 없습니다. 무작위이므로 같은 결과가 다시 선택될 수 있습니다.

작업실 왼쪽에서 Prompt guidance와 Guidance rescale을 0.1 단위로 조절할 수 있습니다. 오른쪽 결과의 **이 시드 사용**을 누르면 선택한 이미지의 시드가 고정되고, 다시 누르면 랜덤 시드로 돌아갑니다. 이미지를 선택하는 것만으로 설정이 바뀌지는 않습니다. 가이던스만 비교하려면 작가 조합과 순서도 고정하세요.
각 메뉴의 생성 버튼 오른쪽 자물쇠는 회색으로 랜덤 시드, 빨간색으로 고정 시드를 표시합니다. 아이콘에 마우스를 올리면 고정된 시드 값을 확인할 수 있습니다. 가이던스 테스트는 선택한 원본 이미지의 시드를 고정해 사용합니다.

## 생성과 대기열

처음에는 **API 없이 체험하기**가 켜져 있습니다. 실제 API 대신 그라데이션 테스트 이미지를 만듭니다.
실제로 생성하려면 **설정**에서 NovelAI API 토큰을 저장하고 체험 모드를 끕니다.
API 토큰은 암호화해 저장됩니다.

대기열은 순서대로 실행되며 각 작업은 추가 당시의 설정을 사용합니다. 중지는 현재 API 요청이 끝난 뒤 적용됩니다.
앱을 닫으면 생성 작업도 종료됩니다. 완료한 결과는 남지만 진행 중 요청과 미실행 대기열은 재개되지 않습니다.
앱을 중복 실행하면 기존 창으로 돌아갑니다. 하단 진행 막대는 현재 대기열의 처리 장수와 전체 장수를 표시하며, 알림과 대기열 창은 3초 뒤 사라집니다. 대기열 창에는 진행·대기 작업과 최근 종료 작업 5개까지만 표시됩니다.

**타율 테스트** 메뉴에서는 하나의 고정 작가 조합을 여러 프리셋에서 시험할 수 있습니다.
랜덤 모드로 실행하면 각 이미지마다 새 조합을 추첨합니다.
시드가 고정된 상태에서 **타율 테스트 시작**을 누르면 확인창이 열립니다. **고정 시드로 시작**을 눌러 진행하거나, 취소한 뒤 작업실에서 시드 고정을 해제하세요.
생성 결과는 같은 메뉴에서 바로 표시됩니다. 큰 프리뷰 아래의 **생성 이미지** 목록은 프리셋별로 구분해 가로로 나열하며 마우스 휠로 넘길 수 있습니다. 썸네일을 선택하거나 좌우 방향키로 이미지를, 위아래 방향키로 프리셋을 이동할 수 있습니다. 큰 이미지를 클릭하면 전체 화면으로 열리며 같은 방향키로 탐색하고 Esc로 돌아옵니다. **테스트 기록**에서 이전 턴도 다시 볼 수 있습니다.

## 가이던스 테스트

왼쪽의 생성 턴별 기록에서 원본 이미지를 선택하고 큰 프리뷰로 확인한 뒤 X축 Guidance와 Y축 Rescale의 시작·끝·간격(resolution)을 지정합니다. 시작 전에 표시되는 총 이미지 수를 확인하고 테스트를 시작하세요. 한 번에 최대 200장을 생성합니다.

프롬프트·네거티브·작가 순서·시드·크기를 고정하고 두 축의 값만 바꿉니다. 모델·Steps·Sampler가 기록된 이미지는 원본 설정을 사용하며, 해당 정보가 없는 과거 이미지는 현재 설정을 사용합니다. 결과는 축 값이 표시된 비교 격자에 쌓이며, **전체 화면**으로 모든 칸을 화면에 맞춰 보거나 확대·축소할 수 있습니다. Esc로 돌아오며, 격자 이미지를 클릭하면 같은 메뉴 안에서 크게 열립니다. 좌우 방향키로 Guidance, 상하 방향키로 Rescale을 이동할 수 있고 하단에 현재 값이 표시됩니다. 테스트 기록은 재실행 후에도 확인할 수 있습니다.

## 기존 데이터 이전

기본 저장 위치는 기존과 같은 `%USERPROFILE%\nai_aclab`입니다.

첫 실행 시 1.x 데이터를 읽어 다음과 같이 이전합니다.

- 수동 세트, 같은 이름의 베이스/캐릭터, 현재 선택 조합, 타율 테스트 조합을 통합 프리셋으로 변환합니다.
- 매칭되지 않은 베이스·캐릭터도 별도 프리셋으로 보존합니다.
- 공통 퀄리티는 기존 전역 설정을 우선하며, 없으면 선택된 베이스의 설정 또는 기존 설정에서 가져옵니다.
- 기존 생성 기록·이미지·작가 설정은 유지합니다. 평점 및 학습 메타데이터는 삭제합니다.
- 이전 전 구조는 `data/app_state.pre-v2.json`에 한 번 백업합니다. 백업에도 토큰과 평점은 남기지 않습니다. 이전 버전의 개별 퀄리티 차이는 이 백업에서 확인할 수 있습니다.

2.0에서 변경한 데이터는 1.x와 호환되지 않습니다. 두 버전을 동시에 실행하지 마세요.
기록 삭제는 목록에서만 제거하며 이미지 파일은 유지합니다.
