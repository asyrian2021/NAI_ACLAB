# NAI ACLAB Studio 2.0.8

- 모든 메뉴에서 **상단 메뉴와 하단 진행 상태를 고정**했습니다. 긴 내용을 스크롤해도 메뉴 이동과 전체 생성 진행률을 바로 확인할 수 있습니다.
- 가운데 작업 영역만 스크롤되도록 바꿨습니다. 가이던스 테스트에서는 원본 이미지 목록과 테스트 내용을 각각 스크롤할 수 있습니다.
- 대기열 상세 창은 스크롤 위치와 관계없이 하단 상태창 바로 위에 열립니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.0.8-Windows-x64-setup.exe`를 실행하세요.
