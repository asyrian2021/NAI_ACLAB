# NAI ACLAB Studio 2.1.3

- **화풍 고르기 이미지가 화면을 꽉 채웁니다.** 비교할 2~3장을 창 크기에 맞춰 여백 없이 최대한 크게 배치합니다. 가로로 넓은 창에서는 조합 설명이 이미지 옆으로 갑니다. 단계 표시와 버튼은 위쪽 한 줄로 모았습니다.
- **더블클릭하면 고르지 않고 확대합니다.** 전에는 더블클릭의 첫 클릭에서 이미지가 바로 골라졌습니다. 이제 한 번 클릭은 고르기, 더블클릭은 확대입니다.
- 화풍 고르기에서 숫자키를 빠르게 연달아 누르면 앞의 선택이 덮어써지던 문제를 고쳤습니다.
- 여러 이미지를 함께 보는 다른 화면(작업실 모아보기, 가이던스 테스트 결과, 타율 검증의 전체 이미지 보기)도 이미지 비율에 맞춰 빈 공간 없이 배치합니다.
- **타율 검증의 방향키를 고쳤습니다.** ← →가 이미지를 건너뛰지 않고 순서대로 이동하며, ↑ ↓로 같은 장면의 다른 후보 이미지로 옮겨 갈 수 있습니다.
- **탈락한 후보도 전체 이미지 보기에서 확인할 수 있습니다.** 칸을 누르면 큰 화면에 "탈락한 후보"·"기준 미달 후보"가 함께 표시됩니다. 실패 라벨도 고칠 수 있습니다.
- 전체 이미지 보기에서 마우스로 누른 칸에 테두리가 남던 문제를 고쳤습니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.1.3-Windows-x64-setup.exe`를 실행하세요.
