# NAI ACLAB Studio 2.0.1

브라우저 기반 1.x에서 Windows 설치형 앱으로 전환한 첫 정식 배포입니다.

- 이미지 감상·비교·모아보기와 생성 턴별 기록 구분을 제공하는 새 작업실입니다.
- 공통 퀄리티·네거티브와 개별 통합 프롬프트 프리셋을 사용합니다.
- 작가 인원·가중치·순서를 무작위 추첨하고, 인원 범위와 고정 조합 드래그 정렬을 지원합니다.
- 평점·그림체 평가와 가중치 학습 기능을 제거했습니다.
- 자동 저장, 시드 고정, Guidance·Rescale 조절과 애니메이션 진행 막대를 제공합니다.

## 설치와 업데이트

`NAI-ACLAB-2.0.1-Windows-x64-setup.exe`를 내려받아 실행하세요. Python·Node.js 설치가 필요하지 않습니다.


- 앱 시작 시 새 버전을 확인합니다.
- 상단 업데이트 버튼에서 변경 사항과 다운로드 진행률을 확인하고 설치할 수 있습니다.
- 서명을 검증한 업데이트만 설치하며, 설치 후 앱이 다시 실행됩니다.
- 이미지 생성 중에는 업데이트 설치를 차단합니다.
- 연결 실패 또는 다운로드 오류가 발생하면 업데이트 창에서 재시도할 수 있습니다.

2.0.0 사용자는 이번 설치 파일을 한 번 실행해야 앱 내 업데이트를 사용할 수 있습니다.
