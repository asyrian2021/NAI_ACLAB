# NAI ACLAB Studio 2.0.7

- **타율 테스트 결과 바로 보기:** 작업실로 이동하지 않고 같은 메뉴에서 생성 결과를 확인할 수 있습니다. 생성 중에도 완료된 이미지부터 표시하며, 이전 테스트 기록도 선택할 수 있습니다.
- 프리셋 설정, 큰 프리뷰, 생성 이미지 목록을 별도 카드로 구분했습니다. 이미지 목록은 프리셋별로 묶어 가로로 나열하며 마우스 휠로 넘길 수 있습니다. 테스트 시작 버튼은 설정 패널 상단으로 옮겼습니다.
- 좌우 방향키로 이미지를, 위아래 방향키로 프리셋을 탐색할 수 있습니다. 이미지를 클릭하면 전체 화면으로 열리며 같은 방향키로 탐색하고 Esc로 돌아옵니다.
- 시드가 고정된 상태에서 타율 테스트를 시작하면 시드 값을 보여주는 확인창이 열립니다. **고정 시드로 시작**을 눌러 진행하거나 취소할 수 있습니다.
- 각 메뉴의 생성 버튼 오른쪽에 시드 상태를 표시합니다. **랜덤 시드는 회색 열린 자물쇠, 고정 시드는 빨간 닫힌 자물쇠**로 구분하며 마우스를 올리면 시드 값을 확인할 수 있습니다. 가이던스 테스트는 선택한 원본 이미지의 시드를 표시합니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.0.7-Windows-x64-setup.exe`를 실행하세요.
