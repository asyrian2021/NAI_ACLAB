# NAI ACLAB Studio 2.0.6

- 생성 중에도 알림과 대기열 창이 3초 뒤 닫히도록 수정했습니다. 하단 진행 막대로 생성 상태를 계속 확인하고, 대기열 버튼으로 상세 상태를 다시 열 수 있습니다.
- 대기열 창에는 진행·대기 작업과 최근 종료 작업 5개만 표시합니다. 이미지와 생성 기록은 그대로 유지됩니다.
- 작업실의 시드 버튼 아래에 **타율 테스트**와 **가이던스 테스트** 바로가기를 추가했습니다. 타율 테스트는 선택한 이미지의 작가 조합을 고정하고, 가이던스 테스트는 해당 이미지와 시드를 선택한 상태로 메뉴를 엽니다. 각 메뉴에서 테스트를 시작할 수 있습니다.
- 가이던스 테스트의 선택 이미지 프리뷰를 확대했습니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.0.6-Windows-x64-setup.exe`를 실행하세요.
