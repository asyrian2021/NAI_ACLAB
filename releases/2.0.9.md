# NAI ACLAB Studio 2.0.9

- **이미지 뷰어를 하나로 합쳤습니다.** 작업실, 타율 테스트, 가이던스 테스트의 확대 화면 모두 마우스 휠로 커서 위치를 기준으로 확대하고, 더블클릭으로 원본 크기(1:1)와 화면 맞춤을 오갈 수 있습니다. 4배 확대에서도 이미지 끝까지 이동할 수 있습니다.
- **비교 방식이 늘었습니다.** 비교 보기에서 나란히 / 슬라이더 / 겹쳐 보기를 고를 수 있습니다. 슬라이더는 화면을 드래그하거나 방향키로 움직입니다.
- **새 이미지가 도착하면 알려 줍니다.** 보던 이미지는 그대로 두고 "새 이미지 N장 · 최신으로 이동" 배지를 띄우며, 생성 중인 자리는 하단 목록에 미리 표시됩니다.
- **오류 알림이 사라지지 않습니다.** 오류는 직접 닫을 때까지 남고, 엔진 연결이 복구되면 자동으로 닫힙니다.
- **삭제를 되돌릴 수 있습니다.** 프리셋·캐릭터·작가 그룹은 삭제 후 "실행 취소"로 되살릴 수 있고, 생성 기록 삭제는 앱 안의 확인 창으로 묻습니다.
- **작가 편집 화면을 바꿨습니다.** 작가를 한 줄씩 관리하고, 작가별로 추첨에서 잠시 빼 둘 수 있습니다. 중복이나 `artist:`가 빠진 줄은 바로 표시되고, 여러 줄을 붙여넣어 한 번에 추가할 수 있습니다. 고정 조합 가중치는 슬라이더로도 조절합니다.
- **단축키를 추가했습니다.** Ctrl+Enter 생성, H 즐겨찾기, 1/2/3 보기 전환, P 기준 고정, +/−/0 확대·축소, `?` 단축키 안내.
- 글자 크기를 읽기 쉽게 키우고, 메뉴 전환·생성·즐겨찾기 등에 짧은 애니메이션을 더했습니다. Windows의 애니메이션 효과 끄기 설정을 따릅니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.0.9-Windows-x64-setup.exe`를 실행하세요.
