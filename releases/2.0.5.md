# NAI ACLAB Studio 2.0.5

- **가이던스 테스트 추가:** 생성 기록에서 원본 이미지를 선택하고, X축 Guidance·Y축 Rescale의 범위와 간격을 지정해 비교할 수 있습니다.
- 선택한 원본의 큰 프리뷰와 확대 보기를 지원하며, 생성 기록을 턴별로 구분했습니다.
- 비교 격자를 전체 화면으로 펼쳐 화면에 맞추거나 확대·축소할 수 있습니다.
- 격자 이미지를 클릭하면 같은 메뉴에서 크게 열립니다. 좌우 방향키로 Guidance, 상하 방향키로 Rescale을 이동하고 하단에서 현재 값을 확인할 수 있습니다.
- 작가 메뉴의 ‘등록 작가 전체 사용’ 옵션 배치와 여백을 개선했습니다.

기존 사용자는 앱 상단의 새 버전 버튼으로 업데이트할 수 있습니다. 처음 설치하는 경우 `NAI-ACLAB-2.0.5-Windows-x64-setup.exe`를 실행하세요.
